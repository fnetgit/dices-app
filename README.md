# Dices App

Um aplicativo simples feito em Flutter para simular o lançamento de dados.

## Sobre o Projeto

O **Dices App** é um aplicativo mobile que apresenta dois dados na tela. O usuário pode tocar em cada dado individualmente para rolá-lo, ou utilizar o botão inferior "ROLAR AMBOS" para rolar os dois dados simultaneamente de forma aleatória.

## Funcionalidades

- Interface amigável com um tema de fundo amarelo.
- Rolar cada dado individualmente tocando sobre ele.
- Rolar os dois dados ao mesmo tempo clicando no botão.

## Pré-requisitos

Antes de começar, você precisará ter o [Flutter SDK](https://flutter.dev/docs/get-started/install) instalado em sua máquina.

## Como Executar

1. Clone o repositório ou faça o download do código-fonte.
2. Navegue até o diretório do projeto no seu terminal:

   ```bash
   cd dices-app
   ```

3. Instale as dependências do projeto:

   ```bash
   flutter pub get
   ```

4. Execute o aplicativo:

   ```bash
   flutter run
   ```

   *(Certifique-se de que há um emulador em execução ou um dispositivo físico conectado).*
